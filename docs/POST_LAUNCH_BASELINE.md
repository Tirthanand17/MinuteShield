# Post-launch baseline

Captured immediately after the public Marketplace launch on 2026-09-19.

- Repository stars: 0
- Forks: 0
- Watchers/subscribers: 0
- GitHub traffic views (14-day API window): 0
- Unique visitors: 0
- Clones: 0
- Unique cloners: 0
- External referrers: none yet

This is intentionally a true zero-point, not a traction claim. Future adoption should be measured against it.

## Signals to watch

1. Repository views and unique visitors.
2. Clones and forks.
3. Stars and repeat contributors.
4. Marketplace installs/usage signals that GitHub exposes.
5. Real issues/questions from users.
6. Repeat execution in demo/customer repositories.
7. Paid-feature requests before building a cloud tier.

Do not infer willingness to pay from stars alone. The $1,000/month target remains a business hypothesis until retention and conversion are observed.
