# Monetization and self-serve acquisition

## Business model

MinuteShield should use an open-core funnel:

- **Free:** preventive PR cost estimate, local policy file, findings, sticky PR comment, job summary.
- **Team Cloud — target $29/month:** central policies, multi-repo history, ownership, weekly savings report, webhooks, longer retention.
- **Org Cloud — target $59/month:** larger repo allowance, policy templates, audit export, consolidated budget views, priority support.

These prices are hypotheses to test, not promises. A simple MRR model is 35 Team subscriptions at $29 = $1,015/month, or 18 Org subscriptions at $59 = $1,062/month, before fees/tax/costs.

## Acquisition without cold selling

1. Publish the free Action to GitHub Marketplace after private development is stable.
2. Make every useful PR report include a small, non-spammy MinuteShield attribution/link.
3. Publish exact-answer documentation pages around expensive runners, matrix expansion, concurrency cancellation, workflow cost estimation, and GitHub Actions budgets.
4. Offer a browser-based public calculator using the same pricing constants.
5. Use a copy-paste install workflow and no mandatory account for the free tier.
6. Put cloud upgrade behind features teams naturally need after installing across multiple repos.

## Budget discipline

The v0.1 Action requires no vendor backend. Development, tests, and GitHub Marketplace distribution can therefore start with near-zero infrastructure spend. Keep the initial ₹3,000 reserve for a domain and any unavoidable launch/payment-provider costs rather than spending on ads.

## Age / payment-provider note

When a paid tier is activated, payment-provider, tax, and business accounts must be opened by an eligible account holder/entity under the provider's terms. Do not bypass age, identity, or KYC requirements.
